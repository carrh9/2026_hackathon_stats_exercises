# Using open-source software as an alternative to GraphPad Prism
In this project, we are interested in re-creating analyses done in GraphPad Prism using JASP and/or Jamovi. This is to explore whether a statistics course currently using Prism can be recreated using open-source software. We’d like to explore ease of use and get an idea of whether analyses and visualisations can be directly recreated, or if there are any key differences or gaps in capabilities. Additionally, we can have a look at other features included in JASP/Jamovi that are not available in Prism, to identify any that may be particular useful. Finally, we can compare JASP and Jamovi, in terms of ease of use and features available, to see if there is a clear winner between the two.

This project contains the exercises currently implemented in GraphPad Prism, as well as the data required to run them. The data may not be in the correct format for JASP or Jamovi, and the exact output of the exercises may have to change, depending on the capabilities of the new software, but overall structure and statistical tests used should be the same (or very similar). Feel free to try both JASP and Jamovi, and/or pick your favourite to try in more detail.

## Software download

[Jamovi](https://www.jamovi.org/index.html) - Jamovi can also be used on the cloud in a browser, if you are unable to download software.
